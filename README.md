1. 适用范围

2. 游戏本体使用的数据
游戏进度：为恢复未完成的一局，游戏在您的设备或 TapPlay 提供的游戏运行环境中保存角色选择、难度选择和该局游戏状态，并保留用于恢复的本地备份。
通关记录：为展示历史通关情况，游戏在本地保存通关时间、该局记录及相应备份。
偏好及解锁进度：为保持您的选择，游戏通过 Unity PlayerPrefs 在本地保存主音量、音效音量和难度通关、解锁进度。
上述数据由游戏行为产生，游戏本体不通过网络将其发送到我们的服务器。我们未为此版本提供开发者云存档、联机、游戏账号登录、广告、应用内购买或联网统计服务。
游戏功能不使用通讯录、相机、麦克风、精确位置，也不要求您在游戏本体内填写姓名、身份证号码、手机号码或支付信息。TapTap 平台可能为其服务要求相关信息或权限，请以平台的单独说明和授权提示为准。

3. TapTap 与 TapPlay 平台服务
您通过 TapPlay 使用本游戏时，TapTap 可能按照其隐私政策处理账号信息、实名验证信息、设备及服务使用信息，并提供未成年人防沉迷服务。游戏本体不会自行获取您的真实姓名或身份证号码。
若您使用或开启 TapPlay 的存档备份等功能，本地游戏数据可能由平台按其规则备份、传输或恢复；这与本游戏开发者自行上传存档不同。本政策关于本地保存的说明不代表 TapTap 平台不联网或不处理数据。
平台数据的查询、删除、账号注销、权限管理以及存档备份设置，请通过 TapTap 提供的入口办理。您可以阅读 TapTap 隐私政策：https://www.taptap.cn/doc/privacy-policy/。

4. 隐私政策网页
本政策网页不包含我们添加的广告、统计脚本、外部字体或用户追踪工具，也不通过网页上传您的游戏存档。
当政策网页托管于 GitHub Pages 且您通过浏览器访问时，GitHub 会为安全目的记录并保存访问者的 IP 地址，无论访问者是否登录 GitHub。该网页托管服务的数据处理适用 GitHub 的隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。这是访问网页时发生的服务行为，不代表离线游戏本体上传存档或身份信息；离线阅读游戏内政策不会发起该网页访问。

5. 您主动联系我们时提供的信息
若您通过邮箱主动反馈问题，我们会收到您发送的邮箱地址、反馈内容以及您自行附上的截图、设备信息或存档。我们仅为回复、定位问题和处理您的请求使用这些信息。
反馈时请避免发送身份证、密码、支付凭证或与问题无关的个人信息；您可以先遮挡截图中的敏感内容。反馈不是正常游玩所必需的，您可以选择不提供。反馈信息仅保留处理请求及履行相关义务所需的期间，目的完成后予以删除，法律法规另有要求的除外。

6. 保存、保护与共享
游戏本体的数据保存在您的设备或平台提供的游戏运行环境中。我们无法远程访问、修改或替您恢复这些本地数据。本地存档使用完整性校验与备份来减少部分损坏风险，完整性校验并不等同于加密，也不能保证在卸载、清除数据、设备故障或平台环境变化后恢复。
我们不通过本游戏出售、对外公开或主动向第三方发送您的本地存档、设置或解锁记录。若您主动向我们提交反馈，我们不会为营销目的使用该反馈信息；依法需要处理或披露时，仅在必要范围内进行。
请妥善保管设备，谨慎使用系统清理功能，并留意 TapPlay 存档备份的实际状态。平台服务的数据保存与跨设备恢复规则，请参阅其单独说明。

您可以在游戏已有界面查看进度、通关记录并修改音量设置。当前版本没有游戏开发者账号，因此没有开发者账号注销流程。
独立安装的 Android 游戏通常可通过系统设置中的“应用信息—存储—清除数据”清除本地游戏数据。该操作可能删除未完成的一局、通关历史、音量设置和解锁进度，不能保证恢复。具体入口以您的设备系统为准。
TapPlay 环境中的游戏数据、备份及恢复由平台管理，请查看 TapTap 的相应设置或联系平台支持。卸载或删除本地数据不一定同时删除平台已有的备份。
您可以随时停止使用或卸载游戏。若您曾主动向我们发送反馈，可通过 2078523752@qq.com 请求查阅、更正、复制或删除我们收到的相关信息，或撤回您对后续使用的同意；我们会在必要核实后依法处理。平台处理的信息请直接向平台提出相关请求。
